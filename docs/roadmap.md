# Roadmap

## 项目目标

围绕“预测沪深300成分股未来一周收益率并构建 Top-5 投资组合”这一任务，建立一套可复现、可扩展、可比赛提交的研究与工程流水线。

最终交付目标：

1. 形成结构化项目仓库与实验规范
2. 跑通从原始数据到 `result.csv` 的全链路
3. 建立强基线与主力深度模型
4. 通过排序优化与组合优化冲击更高收益

## 任务拆解

### A. 文档与规范层

- 明确比赛标签定义与提交格式
- 明确允许使用的数据源与引用要求
- 明确时间切分、评估指标和实验记录模板
- 明确项目目录结构和命名规则

### B. 数据层

- 接入比赛基础日线数据
- 统一股票代码、日期格式、复权口径
- 处理停牌、缺失值和异常值
- 构建交易日历和股票池
- 引入补充公开数据源

### C. 特征与标签层

- 计算基础量价特征
- 计算技术指标与截面标准化特征
- 构建与比赛收益定义一致的主标签
- 构建辅助标签与组合优化标签

### D. 模型层

- 建立树模型基线
- 建立简单深度学习基线
- 复现主力深度模型
- 引入排序损失和市场状态建模

### E. 组合与评估层

- 将预测分数转化为 Top-5 组合
- 实现滚动验证和简易回测
- 记录 IC、RankIC、Precision@K、组合收益
- 生成标准提交文件

## 阶段路线

## Phase 0：方案冻结

目标：

- 把“怎么做”写清楚，避免后续边开发边摇摆

产出：

- `README.md`
- `docs/model_survey.md`
- `docs/sota_survey.md`
- `docs/roadmap.md`

完成标准：

- 任务、路线、优先级、实验矩阵都有书面版本

## Phase 1：最小可运行闭环

目标：

- 跑通数据读取、特征构造、训练、预测、提交导出

工作项：

1. 约定原始数据格式
2. 编写数据集构建脚本
3. 实现基础特征和主标签
4. 训练 baseline 模型
5. 生成 `result.csv`

产出：

- `scripts/build_dataset.py`
- `scripts/train_baseline.py`
- `src/data/*`
- `src/features/*`
- `src/training/*`

完成标准：

- 可以在本地用一份标准 CSV 跑出训练结果与提交文件

当前赛事特殊事项：

- 官方 Q&A 已说明，正式评测时喂给模型的历史数据会覆盖“过去十年到比赛提交最后一天的数据”
- 因此基准仓库中的 `2026-02-28` 只是演示上限，不应作为最终训练数据截止日
- 当前 A 阶段第一次提交建议把数据更新到 `2026-04-24`
- 且本轮提交存在特例：`T+5` 直接复用 `T+4` 数据

因此 Phase 1 的当前优先任务应改为：

1. 拉取扩展到 `2026-04-24` 的最新公开日线数据
2. 使用 `configs/a_stage_round1.yaml` 构建本轮特例标签
3. 优先确保 baseline 结果可复现、可提交

## Phase 2：强基线

目标：

- 建立一个足够强的传统机器学习基线，作为所有深度模型的参照系

工作项：

1. 扩展为 Alpha 风格因子
2. 引入市场上下文特征
3. 做时间切分与滚动验证
4. 记录实验结果

候选模型：

- LightGBM
- XGBoost
- CatBoost

重点指标：

- RankIC
- Precision@5
- Top-5 portfolio return

完成标准：

- 拿到一个稳定优于简单回归的强 baseline

## Phase 3：主力深度模型

目标：

- 用低成本强模型和高贴合模型验证深度路线的真实增益

优先顺序：

1. StockMixer
2. MASTER
3. 简单 MLP/LSTM 对照

工作项：

1. 统一输入张量格式
2. 实现或迁移模型训练入口
3. 跑通固定时间切分实验
4. 与强基线做同口径对比

完成标准：

- 至少一个深度模型在核心排序指标上稳定超过强 baseline

## Phase 4：赛题对齐优化

目标：

- 把“预测更准”变成“提交更强”

工作项：

1. 引入 pairwise/listwise ranking loss
2. 预测超额收益而非原始收益
3. 研究市场状态或 regime-aware 策略
4. 优化权重生成策略

完成标准：

- 在离线回测中明显改善 Top-5 收益

## Phase 5：增强与冲榜

目标：

- 在已有强方案之上叠加结构性改进

候选方向：

- HIST 风格关系建模
- DoubleAdapt 增量适配
- 外生变量建模
- 模型集成
- 不确定性过滤

完成标准：

- 找到至少 1 个能稳定提供增益的增强模块

## 风险清单

### 1. 数据泄漏

高风险点：

- 错误使用未来开盘价或未来指标
- 用全样本统计量做归一化
- 股票池或成分股信息穿越

缓解措施：

- 所有标签统一通过单独函数生成
- 只用历史窗口统计特征
- 训练、验证、测试严格按时间切分

### 2. 幸存者偏差

高风险点：

- 只使用当前成分股回看历史

缓解措施：

- 初版文档中明确说明假设
- 后续尽量恢复时变股票池或至少保留剔除逻辑

### 3. 评价目标错位

高风险点：

- 只盯 MSE，不看排序和组合收益

缓解措施：

- 每次实验必须同时记录 RankIC 和 Top-K 收益

### 4. 深度模型成本失控

高风险点：

- 过早投入复杂模型

缓解措施：

- 先把强 baseline 做稳
- 深度模型只按优先级逐个推进

## 实验记录模板

建议每次实验都记录以下字段：

- 实验编号
- 数据版本
- 股票池版本
- 标签版本
- 特征版本
- 模型名称
- 关键超参数
- 时间切分区间
- 训练时长
- IC / RankIC
- Precision@5
- Top-5 portfolio return
- 是否生成提交
- 结论
- 下一步动作
