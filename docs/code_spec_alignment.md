# Code Spec Alignment

## 目标

根据官方《代码规范2026.docx》，本项目需要同时满足：

1. 可从训练开始复现
2. 在指定机器资源下运行
3. 预测时间不超过 5 分钟
4. 训练时间不超过 8 小时
5. 提交项目文件大小不超过 10G
6. 复现时不得联网
7. 目录结构与脚本入口符合官方要求

本文档用于记录当前仓库与官方规范的对齐情况。

## 官方关键要求摘要

### 1. 固定随机种子，可从训练过程开始复现

当前状态：

- 已满足基础条件
- 当前配置文件中已有 `seed: 42`
- baseline 训练链路可从原始数据构建、训练、预测、生成提交

后续建议：

- 在后续深度模型中统一把随机种子写进训练脚本

### 2. 指定机器资源限制

官方约束：

- CPU: `i7-13650H`
- 内存: `16GB`
- 显存: `8GB`
- 存储: `50GB`
- 训练时间: 不超过 `8` 小时
- 预测时间: 不超过 `5` 分钟

当前状态：

- 当前 baseline 为 `LightGBM`
- 数据规模和训练耗时都在可接受范围内
- 更复杂模型后续需要专门记录训练时长

### 3. 禁止联网复现

官方要求：

- 复现训练和预测时不得联网

当前状态：

- 研究阶段允许联网抓公开数据
- 但最终提交版本必须把训练/推理所需数据、模型和代码全部打包进镜像或挂载目录

结论：

- 当前研究仓库已适合开发
- 最终提交时必须切到离线复现模式
