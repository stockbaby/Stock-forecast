# Benchmark Comparison

## 1. 赛题基准代码是什么

官方公开基准仓库：
- [Sherlock1956/THU-BDC2026](https://github.com/Sherlock1956/THU-BDC2026)

根据其公开 `README`，基准代码的核心方案是：
- 输入：每只股票过去 `60` 个交易日的量价与技术特征序列
- 特征：`39` 特征或 `158+39` 特征
- 模型：`StockTransformer`
- 目标：做同一交易日内全部候选股票的排序
- 损失：加权排序损失
- 输出：前 `5` 只股票，固定等权 `0.2`

也就是说，官方 baseline 的定位本身就是：
- 排序学习
- 序列建模
- Top-5 组合输出

它不是一个非常弱的传统 baseline，而是一条已经比较像“正式比赛方案”的深度路线。

### 3.2 严格数值对比层面

这一层需要诚实说明：

**我们还没有在仓库内完成一次“官方基准代码原样复现后再做严格同仓数值对比”。**

所以当前还不能严谨地说：
- “我们的结果已经严格高于官方 baseline 的某个固定数值”

## 6. 下一步最值得补的事情

如果要把“和赛题基准代码比”这件事做得最扎实，建议下一步补：

1. 复现官方 baseline
2. 在相同数据窗口下，生成它的 `result.csv`
3. 用当前仓库的 `evaluate_submission_return.py` 做同口径对比
4. 记录：
   - 官方 baseline 本地回看收益
   - 我们当前 `StockMixer / MASTER / ensemble` 的本地回看收益

到这一步之后，就可以形成真正严格的 benchmark comparison。

## 7. 已完成的严格同仓复现结果

这一项现在已经完成。

复现口径：
- 官方仓库：`external/THU-BDC2026`
- 训练输出目录：`external/THU-BDC2026/model/60_158+39`
- 官方预测文件：`external/THU-BDC2026/output/result.csv`
- 训练数据与我们当前仓库共用同一源数据窗口
- 回看口径：
  - 参考交易日 `T = 2026-04-17`
  - 买入日 `2026-04-20`
  - 卖出日 `2026-04-24`

官方 baseline 本地回看收益：
- `0.023500505822503896`

严格同仓对比结果：

| Method | Local Return | Improvement vs Official |
|---|---:|---:|
| Official baseline | 0.02350 | 0.00000 |
| LightGBM | 0.03386 | +0.01036 |
| MASTER | 0.06097 | +0.03747 |
| StockMixer | 0.06332 | +0.03982 |

解释：
- 官方 baseline 这次窗口能抓到一只强票 `600482`，但固定等权 Top-5 里也包含了一只明显拖累收益的 `600489`。
- `LightGBM` 已经能稳定超过官方 baseline，但领先幅度有限，仍更像强基线。
- `MASTER` 和强化版 `StockMixer` 都明显超过官方 baseline，且领先幅度接近 `3.7% ~ 4.0%`。
- 在这个最近窗口下，当前最强提交稿仍是 `StockMixer`；如果更看重验证集综合表现，`MASTER` 更稳。

复现时做过的兼容性处理：
- 官方 `train.py` 和 `predict.py` 在 Windows 环境下都会因 `multiprocessing.Pool` 触发 `WinError 5`，已增加单进程回退，不改变训练/预测逻辑。
- `SummaryWriter` 在当前环境下也做了失败回退，不影响模型训练与权重保存。

因此，现在已经可以严谨地说：
- 我们当前主线模型在**严格同仓、同窗口、同公式**下，已经实测超过官方 baseline。

本节结果优先级高于本文前面“尚未完成严格同仓复现”的历史描述，应以本节为准。

## 8. 从官方 Baseline 吸收什么

虽然当前结果已经超过官方 baseline，但官方方法里仍有三点值得继续吸收：

1. `Top-5` 倾斜的排序损失
- 官方 `WeightedRankingLoss` 明确强调头部样本。
- 这比普通收益回归更贴合赛题目标。

2. 更长 lookback 的系统验证
- 官方默认 `60` 日序列。
- 我们后续可以在 `StockMixer / MASTER` 中更系统地比较 `30/45/60`。

3. 固定等权备选组合
- 官方固定输出 Top-5 等权 `0.2`。
- 虽然不一定收益最强，但很稳健，也适合作为保守候选提交稿。

因此，后续与官方 baseline 相关的优化，不是回退到它的整套方案，而是：
- 吸收它的 Top-5 倾斜目标思想
- 保留固定等权备选提交稿
- 在更强模型上继续做目标函数迁移
