# Model Survey

## 文档目标

本文档聚焦“本项目实际值得投入复现和改造的模型路线”，不追求罗列所有股票预测论文，而是回答三个问题：

1. 哪些模型最适合当前比赛任务
2. 哪些模型最值得先复现
3. 哪些模型更适合作为后续增强或创新储备

## 任务视角下的选型原则

对于“沪深300未来一周收益率预测 + Top-5 组合构建”这一任务，模型选型要优先满足：

- 适合截面排序，而不是只优化回归误差
- 能处理多股票联合信息，而不是完全独立逐股预测
- 对有限样本和金融非平稳性有一定鲁棒性
- 工程复现成本可控

## 模型路线总览

| 路线 | 代表模型 | 核心价值 | 适合阶段 | 建议优先级 |
|---|---|---|---|---:|
| 表格强基线 | LightGBM / XGBoost | 快、稳、强、可解释 | 项目起步 | 1 |
| 简单深度基线 | MLP / LSTM / GRU | 校验深度训练链路 | 早期对照 | 2 |
| 轻量强深度 | StockMixer | 成本低、性能强 | 主力阶段 | 3 |
| 市场引导深度 | MASTER | 与 CSI300 任务高度贴合 | 主力阶段 | 4 |
| 关系图增强 | HIST | 强化股票间结构关系 | 增强阶段 | 5 |
| 排序目标增强 | Pairwise/Listwise ranking | 对齐赛题 Top-K 目标 | 增强阶段 | 6 |
| 漂移适配 | DoubleAdapt | 缓解市场非平稳 | 后续增强 | 7 |
| 通用 backbone 改造 | iTransformer / TimeXer | 支撑研究型创新 | 后续探索 | 8 |

## 1. 表格型强基线

### LightGBM / XGBoost

推荐结论：

- **必须先做**

原因：

- 在量化选股类任务中，树模型对结构化因子数据非常强
- 训练速度快，能快速验证数据与标签是否正确
- 作为深度模型对照线非常可靠

适合输入：

- 基础量价特征
- 技术指标
- 截面标准化因子
- 指数和市场上下文特征

适合输出：

- 未来 5 日收益率回归
- 超额收益回归
- 结合排序后处理生成组合

优点：

- 训练快
- 调参成本低
- 对中小样本更稳

缺点：

- 难以自然建模股票间复杂关系
- 对时序交互的表达能力有限

项目中的角色：

- 强 baseline
- 数据链路检查器
- 最终集成候选

## 2. 简单深度基线

### MLP / LSTM / GRU

推荐结论：

- **建议做，但不要重投入**

作用：

- 帮我们确认深度学习训练流程、张量组织、损失设计和验证逻辑都没问题
- 为 StockMixer、MASTER 提供低门槛深度对照

优点：

- 容易实现
- 可用于 sanity check

缺点：

- 在股票任务上往往不是最终最强方案

项目中的角色：

- 早期对照
- 排错工具

## 3. 主力深度模型

### StockMixer

推荐结论：

- **第一主力深度模型**

为什么优先：

- 训练成本低于复杂 Transformer / GNN
- 直接针对股票任务设计
- 官方结果强调高性能同时降低运行和显存成本

模型特点：

- indicator mixing
- time mixing
- stock mixing

适合本项目的原因：

- 我们的比赛样本量有限，不适合一开始上太重的模型
- 它在“性能 / 难度 / 算力”之间平衡很好

潜在风险：

- 官方主要在美股基准验证，迁移到 A 股时仍需谨慎做验证

项目中的角色：

- 第一个真正值得重投入的深度模型

### MASTER

推荐结论：

- **第二主力深度模型**

为什么重要：

- 使用市场状态引导特征选择
- 显式建模股票间瞬时与跨时间相关性
- 实验直接基于 CSI300 / CSI800

适合本项目的原因：

- 你的任务就是 A 股成分股预测
- 它比一般通用时序模型更接近比赛场景

优点：

- 任务贴合度高
- 同时兼顾排名和组合指标

缺点：

- 数据组织更复杂
- 对复现细节更敏感

项目中的角色：

- 高贴合主力模型
- 冲击更高收益的关键路线

## 4. 图关系增强模型

### HIST

推荐结论：

- **建议在主力模型稳定后再做**

模型价值：

- 把股票之间的关系显式引入建模
- 对沪深300这种成分股池非常合理

适用前提：

- 我们已经有稳定 baseline 和主力模型
- 我们准备投入额外工程成本构建行业/概念关系

优点：

- 对 A 股任务贴近
- 很适合做结构增强

缺点：

- 工程复杂度提升明显
- 关系数据质量会显著影响收益

项目中的角色：

- 关系增强模块
- 创新点候选

## 5. 目标函数增强

### Ranking Loss

推荐结论：

- **极值得投入**

为什么重要：

- 这道题最终拼的是 Top-5 选股和组合收益
- 如果模型回归误差更小，但无法把最高收益股票排到前面，比赛收益未必更好

可选方向：

- pairwise ranking loss
- listwise ranking loss
- 回归头 + 排序头联合训练

项目中的角色：

- 赛题导向优化核心模块

## 6. 训练范式增强

### DoubleAdapt

推荐结论：

- **作为后续增强，不作为首发**

为什么值得保留：

- 金融数据分布漂移强
- 比赛测试区间很可能与训练区间风格不同

为什么不适合先做：

- 调参复杂
- 成本更高
- 需要稳定基线作为参照

项目中的角色：

- 市场风格切换应对模块

## 7. 通用时序 Backbone

### iTransformer

推荐结论：

- **适合作为后续研究型 backbone**

作用：

- 多变量联合建模能力强
- 可作为未来自定义股票模型的基础骨架

限制：

- 不是股票任务原生模型
- 需要自己补足市场上下文、排序和组合逻辑

### TimeXer

推荐结论：

- **当我们决定引入丰富外部变量时再考虑**

作用：

- 更适合处理指数、行业、宏观、资金流等外生变量

限制：

- 仍然不是 stock selection 原生框架

## 8. 当前选型结论

结合任务目标、可复现性和算力成本，当前推荐的主路线如下：

### 第一层：必须做

1. LightGBM baseline
2. Alpha 风格特征工程
3. 滚动时间切分验证

### 第二层：主力深度模型

1. StockMixer
2. MASTER

### 第三层：赛题导向增强

1. ranking loss
2. 组合优化
3. 超额收益标签

### 第四层：结构增强与创新

1. HIST
2. DoubleAdapt
3. 外生变量增强

## 9. 优先复现顺序

| 顺序 | 路线 | 目标 |
|---|---|---|
| 1 | LightGBM + 基础特征 | 跑通闭环 |
| 2 | LightGBM + Alpha 风格特征 | 建立强基线 |
| 3 | 简单 MLP / LSTM | 校验深度训练流程 |
| 4 | StockMixer | 拿到第一主力深度结果 |
| 5 | MASTER | 验证高贴合 stock-specific 模型 |
| 6 | ranking loss | 提升 Top-K 质量 |
| 7 | 组合优化 | 提升最终提交收益 |
| 8 | HIST | 做关系增强 |
| 9 | DoubleAdapt / TimeXer / iTransformer | 做后续增强 |

## 10. 最终建议

如果时间和算力都有限，本项目最值得投入的组合是：

1. `LightGBM strong baseline`
2. `StockMixer`
3. `MASTER`
4. `ranking loss + portfolio construction`

这条路线最符合当前比赛需求，也最可能在有限投入下得到可用结果。
## 11. 官方 Baseline 的可借鉴之处

在完成官方 baseline 原仓复现和严格同仓对比后，可以更明确地评价它的参考价值。

### 11.1 值得学习的部分

1. 排序任务定义
- 官方把任务直接做成同日截面排序，而不是普通回归。
- 这与比赛最终只关心 Top-5 组合收益的目标一致。

2. `WeightedRankingLoss`
- 官方损失函数对 Top-5 相关样本施加更高权重。
- 这一点非常值得迁移到我们当前 `StockMixer / MASTER` 的目标函数里。

3. `60` 日序列长度
- 官方默认使用过去 `60` 个交易日。
- 这提供了一个很有价值的长度参考，说明更长的中短期上下文可能对排序有帮助。

4. 固定等权输出
- 官方最终输出固定等权 `0.2` 的 Top-5 组合。
- 这虽然不一定最优，但足够稳健、可复现，也适合作为保守候选方案。

### 11.2 不必原样照搬的部分

1. 单一模型路线
- 官方只走 `StockTransformer` 一条主线。
- 我们已经验证，多模型路线在研究和实战上都更有价值。

2. 固定等权作为唯一方案
- 这次严格同仓结果表明，动态权重的 `StockMixer / MASTER` 已经能明显超过官方 baseline。
- 因此固定等权更适合作为备选，而不是唯一组合方式。

3. 特征与市场上下文较少
- 官方方法没有像我们这样显式加入 regime、style-group、相对指数等增强特征。

### 11.3 对本项目的直接启发

后续最值得吸收的不是官方的整套结构，而是这三个思想：
- Top-5 倾斜的排序目标
- 更系统地比较 `30/45/60` 日 lookback
- 保留“固定等权备选提交稿”用于稳健性对照

## 12. Backbone 落地结果

文档里提到的通用 backbone 方向，本轮已经先落地并评测了 `iTransformer`。

实验结果：
- `RankIC = 0.0087`
- `Precision@5 = 0.0242`
- `Top-k portfolio return = 0.0053`
- 最近窗口本地回看收益：`-0.01166`

结论：
- `iTransformer` 作为研究型 backbone 参考是有价值的。
- 但在当前比赛设定下，它明显不如更 stock-specific 的 `StockMixer / MASTER`。
- 因此后续如果还做 backbone 路线，更合理的是：
  - 只把它保留为方法研究参考
  - 主力继续围绕 `StockMixer / MASTER` 优化
