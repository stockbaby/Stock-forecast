# 代码说明

## 环境配置

- Python 3.11
- 主要依赖：
  - pandas
  - numpy
  - PyYAML
  - scikit-learn
  - lightgbm
  - baostock
  - akshare

## 数据

当前主要使用公开可获取数据：

1. `baostock` 获取沪深300成分股历史后复权日线
2. `baostock` 获取沪深300指数历史数据
3. 可选使用 `AkShare` 对最近窗口进行尾部补全

训练与推理最终使用的数据需离线放置于 `app/data/` 挂载目录中。

## 预训练模型

当前 baseline 不使用预训练模型。

## 算法

### 整体思路介绍

本项目当前采用轻量且可复现的基线方案：

1. 读取股票日线和指数日线
2. 构造基础量价特征与指数上下文特征
3. 构造与赛题收益定义一致的标签
4. 训练 `LightGBM` 模型预测未来收益
5. 选择得分最高的最多 5 只股票并生成权重

### 方法的创新点

当前阶段重点在于：

- 严格对齐赛题收益定义
- 引入指数上下文特征
- 对 A 阶段首轮的 `T+5` 复用 `T+4` 特例做配置化处理

### 网络结构

当前 baseline 为树模型，不涉及神经网络结构。

### 损失函数

当前使用回归目标拟合未来收益率。

### 数据扩增

当前不使用数据扩增。

### 模型集成

当前不使用模型集成。

### 算法的其他细节

- 使用时间切分验证
- 默认输出不超过 5 只股票
- 权重和不超过 1

## 训练流程

1. 准备 `app/data/stock_data.csv`
2. 可选准备 `app/data/hs300_index.csv`
3. 运行 `train.sh`
4. 输出训练结果与模型文件

## 推理流程

1. 确保数据与模型已准备好
2. 运行 `test.sh`
3. 在 `app/output/result.csv` 中生成最终结果

## 其他注意事项

- 当前仓库同时保留研发目录与 `app/` 打包目录
- 最终提交前应在离线环境下完整验证
- 如使用额外开源数据和模型，需要按官方要求报备链接和 md5
